# Contributing

This repository is an exact mirror of the live lab at https://kiranvk.me/ai/wumpus/.
Every deploy of the website publishes the same files here, so what you read is what students run.

## How to contribute
1. Open an issue first for anything bigger than a typo: a wrong verdict, a confusing hint, a new exercise, a bug on a phone.
2. Fork, make the change, run the tests (see README → "Run it locally"), and open a pull request.
3. Contributions are reviewed, merged into the website source, deployed, and then appear here through the next sync.
   Your commit is credited in the pull request and in the release notes.

## Ground rules
- Keep it free: no paywalls, logins or tracking beyond the existing anonymous page analytics.
- Never commit API keys. AI features use the student's own key in the browser or a server-side config file outside the web root.
- No student data in issues or pull requests (names, roll numbers, screenshots with personal details).
- Teaching content must match the KTU syllabus the lab serves; cite the source of new exercises.
